El bot corre en [hosting.eventsmc.xyz](https://hosting.eventsmc.xyz). Tu cuenta tiene acceso a:

| Sección | |
| --- | --- |
| **Console** | Registro en vivo, encender, apagar y reiniciar. |
| **Startup** | Token del bot, ID de la aplicación e ID del servidor. |
| **Schedules** | Tareas programadas: reinicios o copias de seguridad a una hora. |
| **Users** | Dar acceso a otras personas de tu equipo. |
| **Backups** | Crear y restaurar copias. No se descargan. |

No hay acceso a los archivos: el código del bot no se entrega.

## Actualizaciones

Cada arranque trae la última versión. Para actualizar, basta con **Restart**.

## Si se cae

El bot se vuelve a levantar solo, con una espera creciente si falla varias veces seguidas.
El motivo queda en **Console**.
