description: "De la compra al bot en línea"
---

## 1. Contrata

En [clientes.eventsmc.xyz](https://clientes.eventsmc.xyz) → Hosting → **Events BOT**, con la
licencia **Pack Completo** o **Base** y los módulos que quieras.

Al pagar se crea el servidor del bot en [hosting.eventsmc.xyz](https://hosting.eventsmc.xyz).
El usuario y la contraseña del panel están en tu servicio, en el área de clientes.

## 2. Crea la aplicación en Discord

1. [Discord Developer Portal](https://discord.com/developers/applications) → **New Application**.
   El nombre y el icono son los que verá tu comunidad.
2. **Bot** → **Reset Token** y copia el token.
3. En la misma pestaña, activa los intents que pidan tus módulos:

| Intent | Lo necesitan |
| --- | --- |
| **Server Members Intent** | Tickets, Logging, Niveles, Sorteos |
| **Message Content Intent** | Tickets, Logging, Niveles, Counting, Autoreacciones |

<Warning>
  Sin el intent que pide un módulo, el bot no llega a conectarse.
</Warning>

4. **OAuth2 → URL Generator**: ámbitos `bot` y `applications.commands`, permiso
   **Administrador** (o los concretos de cada módulo). Abre la URL e invita al bot.

## 3. Pon el token en el hosting

[hosting.eventsmc.xyz](https://hosting.eventsmc.xyz) → tu bot → **Startup**:

| Variable | Valor |
| --- | --- |
| Token del bot | El token del paso 2 |
| ID de la aplicación | Developer Portal → General Information → Application ID |
| ID del servidor de Discord | Clic derecho en tu servidor → Copiar ID del servidor |

Con el ID del servidor, los comandos aparecen al momento. Sin él, tardan hasta una hora.

Vuelve a **Console** y pulsa **Restart**. Cuando la consola diga `Conectado como …`,
el bot está en línea.

## 4. Configúralo en Discord

El bot te escribe por privado (al dueño del servidor) con el botón **Empezar**: color,
presencia y módulos, paso a paso. Después, cada módulo se ajusta desde `/configurar` → **Configurar
un módulo**. Ver [Configurar el bot](/bot/configurar).

## 5. (Opcional) Vincúlalo al panel

[panel.eventsmc.xyz](https://panel.eventsmc.xyz) → **Events BOT** → **Vincular un bot**, y el
código en `/configurar` → **Panel de Events**. Ver [Panel de Events](/bot/panel).
